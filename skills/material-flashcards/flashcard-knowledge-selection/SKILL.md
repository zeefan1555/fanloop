# 筛选高价值知识

以已确认复习目标和来源理解为边界，选择值得长期主动回忆的知识，不把原文目录机械变成卡片清单。

## 选择标准

对每个候选判断：

- **长期价值**：过一段时间仍值得准确回忆，而非一次性安排或临时细节；
- **现实适用性**：能支持未来的解释、区分、决策、识别或行动；
- **优先级**：忘记成本、出现频率和与目标的相关度足够高；
- **证据充分性**：答案能由来源事实、保留归因的判断或用户确认支持；
- **独立价值**：不是只有放在列表里才有意义的孤立成员。

合并语义重复项。排除行政安排、装饰性标题、机械列表/集合转换、无支持的一般化结论、会误导的未解矛盾和没有独立复习价值的细节。候选数为 `0..N`，不得固定数量，也不得按概念、情境、行为类型配额凑数。

## 零卡是成功结果

若没有任何候选值得长期复习，写入本地选择文件，记录完整理由；向用户只展示：

- `card_count=0`；
- 不含正文或个人细节的分类级排除理由；
- Vault 零写入；
- 可以调整复习目标后创建一个新 Requirement 重新开始。

只有该安全说明已经真实展示后，才上报 `no_valuable_knowledge` terminal。不得为了避免零卡而降低门槛。

## 产物与回流

非零结果为带来源定位、证据状态、用途和优先级的候选列表，只写 Requirement Root 内权限受限、通用命名的选择文件。Summary 与 Evidence 只含相对路径、SHA、固定分类、候选数量和最小非敏感摘要。

完成时上报 `knowledge_selected`。发现目标、来源理解或选材本身有误时，只上报最早受影响的 `review_goal_changed`、`source_understanding_changed` 或 `knowledge_selection_changed`。
