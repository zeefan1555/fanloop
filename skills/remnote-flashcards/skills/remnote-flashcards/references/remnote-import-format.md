# RemNote CLI 卡片语法

写入通过同 Workflow 的 [remnote-cli](../../remnote-cli/SKILL.md) 使用当前 CLI/Bridge 公开支持的 Markdown 语法；先读取实际 `create`、`insert-children` 或 `journal --help`，按 `--content-file` 传输并回读真实结构。下列格式用于内容表达与已有卡片识别，不另引入 MCP 工具入口。

## 新建或改写卡片：统一使用多行格式

普通卡先按 [制卡 Skill 的卡片写作](../SKILL.md#卡片写作) 区分卡型。原子术语卡用短费曼三行，不用 STAR。组合卡才用 STAR。学习用组合卡四段都要写，R 是一句口诀，不省略。原文导入／摘录仍按对应模式保真，两种背面都不套。一批完整例子见 [市盈率干跑示例](example-pe-valuation.md)。

原子术语卡：

```markdown
- PE ===
    - 正式定义：一行定义或公式。术语只放这里。
    - 白话类比：一句给大约 8–10 岁小朋友的日常场景，这一行没有未解释的术语。
    - 例子：可选的一句口算；没有就删掉。
```

组合卡：

同一批先放原子术语卡，再放组合卡。原子卡标题是短名，例如 `PE`。长搜索句是这张标题卡的别名，用 `getOrCreateAliasWithText` 或 `update --add-aliases` 加上。组合卡引用标题卡 Rem，不引用返回的别名 Rem，否则点击会打开没有背面的别名页。标题是 `PE` 时行内显示 `[[PE]]`。直接写 RichText 用 `{"i":"q","_id":"<标题卡 Rem ID>"}`。`flashcards apply` 答案写 `{"remId":"<标题卡 Rem ID>"}`。它的问题字段不会解析括号；正面用 Markdown 导入或 `update --title`，并写 `[[id:<标题卡 Rem ID>]]`。

```markdown
- 刚学完 [[PE]]：小明的摊多了一笔生日礼，两个摊卖价都是 20 块。小明的摊是真的更便宜吗？ ===
    - S — Situation：背景
    - 小明和小红各有一个柠檬水摊，卖价都是 20 块。小红卖柠檬水赚了 4 块。小明也算出 4 块，可其中 2 块是奶奶给的生日礼，明年没有。两个摊看起来一样便宜，这就是容易看错的地方。
    - ​
    - T — Task：任务／目标
    - 你要学会：先问今年这 4 块明年还在不在，别把只来一次的生日礼当成每年都会赚的钱。
    - ​
    - A — Action：行动
    - 小红明年还会赚 4 块。卖价 20 块，20 除以 4 等于 5，等于一次付了 5 年赚的钱。小明今年也算出 4 块，所以也是 5，看起来一样便宜。明年生日礼没了，只剩卖柠檬水的 2 块。20 除以 2 等于 10，等于要付 10 年赚的钱。点开 [[PE]] 看付了几年的钱，点开 [[EPS]] 看钱怎么分到每一份。
    - ​
    - R — Result：结果
    - 口诀：只来一次的钱，别当成每年都有。
```

组合卡段间看似空白的 Rem 各包含一个 `U+200B` 零宽空格，用于保留实际段落之间的视觉空行。学习用组合卡保留 S、T、A、R 四段和段间空行，不省略 R。原子术语卡不插入这些空行。

`===` 卡片的答案正文不要写 `→`、`←`、`⇒`、`⇐`、`>>`、`<<` 或同类箭头。这些符号会在练习时多出一张嵌套卡。算术写成「20 除以 2 等于 10」，或只用 `=`、`÷`。下面「已有卡片的语法参考」里的 `>>`、`<<` 是别的卡型的分隔符，不是多行答案里的写法。

## 已有卡片的语法参考

```markdown
- 正向问题 >> 答案
- 答案 << 反向问题
- 术语 <> 定义
- 概念 :: 定义
- 属性 ;; 值
- 包含{{隐藏答案}}的文本
- 有序答案 >>1.
    - 第一步
    - 第二步
- 选择题 >>A)
    - 正确答案
    - 干扰项
```

这些格式用于检查时识别已有卡片。新建或改写卡片统一使用上方的多行格式，并遵循 [SKILL.md](../SKILL.md) 中的“卡片写作”规则。

`>>A)` 卡片的第一个子项是正确答案。
