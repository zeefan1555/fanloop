# RemNote CLI 卡片语法

写入通过同 Workflow 的 [remnote-cli](../../remnote-cli/SKILL.md) 使用当前 CLI/Bridge 公开支持的 Markdown 语法；先读取实际 `create`、`insert-children` 或 `journal --help`，按 `--content-file` 传输并回读真实结构。下列格式用于内容表达与已有卡片识别，不另引入 MCP 工具入口。

## 新建或改写卡片：统一使用多行格式

普通卡内容遵循 [STAR 通用解释结构](../SKILL.md#star-通用解释结构)；R 按需省略，原文导入／摘录仍按对应模式保真，不套用 STAR。

```markdown
- 问题 ===
    - S — Situation：背景
    - 相关背景、约束和问题
    - ​
    - T — Task：任务／目标
    - 要达到或解释的目标
    - ​
    - A — Action：行动
    - 白话答案、原理和相关取舍
    - ​
    - R — Result：结果
    - 有依据的效果、验证或边界
```

段间看似空白的 Rem 各包含一个 `U+200B` 零宽空格，用于保留实际段落之间的视觉空行；省略 R 时同时省略其标题、正文及前面的空行。

## 已有卡片的语法参考

```markdown
- 正向问题 >> 答案
- 答案 << 反向问题
- 术语 <> 定义
- 概念 :: 定义
- 属性 ;; 值
- 包含{{隐藏答案}}的文本
- 有序答案 >>1.
    - 第一步
    - 第二步
- 选择题 >>A)
    - 正确答案
    - 干扰项
```

这些格式用于检查时识别已有卡片。新建或改写卡片统一使用上方的多行格式，并遵循 [SKILL.md](../SKILL.md) 中的“卡片写作”规则。

`>>A)` 卡片的第一个子项是正确答案。
