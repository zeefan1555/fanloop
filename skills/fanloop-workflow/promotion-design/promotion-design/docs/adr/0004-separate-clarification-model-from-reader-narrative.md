# 将澄清模型与读者正文彻底分开

`promotion-design` 继续把需求 Context 中的稳定节点和依赖图作为完备性、切片与回流的事实源，
但最终 `方案.md` 不再展示这些编号或映射。正文固定使用“现状、目标、难点、业务特点、业界调研、
解决方案、效果、规划”八段结构：现状、目标和业务特点各三项，难点与业界调研各二到三项。

不再采用把澄清台账直接展开成七段正文的做法。那种方式易于机器核对，却迫使评审者阅读
内部模型；新的正文投影保留模型的语义与门禁，把机器证据留在 Context、ADR 和 Trace。复杂
角色边界或状态回流可用飞书画板辅助，但正文必须保留不依赖图片的完整结论。
