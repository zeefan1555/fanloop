# 在 Promotion Design 内使用双向反馈影响切片

用户反馈可能修改目标、问题、手段或效果。决定由 `promotion-design` 读取既有 `方案.md`、最新反馈以及更新后的 Context/ADR，把反馈定位为依赖图中的变更种子：反向复核其成立前提，正向重算依赖它的内容，只改写受影响子图；首次生成仍执行自顶向下的全量设计。

不采用整篇无差别重写，因为它会丢失已确认内容并扩大回归面；也不拆出新的切片 Skill 或持久化分析文件，因为当前写作叶子 Skill 已拥有文档语义，结构化影响清单通过现有 Driver Evidence 进入 Trace 即可。最终 `方案.md` 保持纯净，多种子按影响并集合流，冲突时回到澄清。
